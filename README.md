# Нутриционный Телеграм-Бот

Этот бот помогает пользователю рассчитать базальный уровень метаболизма (BMR), рекомендованную калорийность и распределение макронутриентов (белки, жиры, углеводы) в зависимости от пола, возраста, роста, веса и цели (сброс, поддержание, набор веса).

## 🚀 Возможности

- Ввод и сохранение персональных данных
- Просмотр введённых данных
- Расчет BMR по формуле Миффлина-Сан Жеора
- Расчет суточной калорийности на основе цели
- Расчет макронутриентов в граммах

## 📦 Установка

1. Клонируйте репозиторий:

git clone https://github.com/yourusername/nutrition-bot.git
cd nutrition-bot

2. Установите зависимости:

pip install -r req.txt

3. Создайте файл .env и добавьте ваш токен:
TELEGRAM_API_TOKEN='your_bot_token_here'

4. python main.py

## В Телеграме используйте команды:

/start — Начало работы с ботом

/set_data — Ввод или изменение данных

/view_data — Просмотр текущих данных

/calculate_macros — Получить рекомендации по калориям и макроэлементам
